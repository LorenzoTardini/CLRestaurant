# CLRestaurant
### A simple cooking game built with JavaFX

CLRestaurant is an educational game for children set in a virtual restaurant. The player has one minute to fulfill as many orders as possible. The game helps develop the ability to recognize ingredients and arrange them in the correct sequence to prepare dishes like burgers and pizzas.

### **Table of Contents**
* Introduction
* Usage

### **Introduction**

In CLRestaurant, the player takes on the role of a chef in a restaurant and must prepare dishes ordered by customers as quickly as possible. Orders may include burgers or pizzas with a varying number of ingredients that must be added in the correct order. The game ends after one minute, and the goal is to accumulate the highest score.

#### Game Rules

* Orders: Each order requires the preparation of a burger or pizza with specific ingredients.
* Time: The player has 60 seconds to complete as many orders as possible.
* Scoring: A correct order adds points, while an incorrect order deducts points. 
* Game Features:
  * Refresh: If the player realizes they’ve made a mistake, they can refresh the current order and try again.
  * Skip: The player can skip an order if they find it too difficult.
  The game was developed in Java using the IntelliJ IDEA integrated development environment.


### Usage

Once the game starts, you will be guided through the steps needed to prepare customer orders. Use the available commands to add the ingredients and confirm the order:

* Select Ingredients: To add ingredients, press the buttons that represent the ingredients in the correct order.
* Bell: Press the bell button to submit the completed order.
* Refresh: You can refresh the current order if you make a mistake.
* Skip: If an order is too difficult, you can skip it.

The game will provide immediate feedback on your score based on the correctness of the orders.``
